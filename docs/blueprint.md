# **App Name**: QuizVantage

## Core Features:

- AI Content Extractor Tool: Admin tool that automatically parses questions, choices, and explanations from pasted PDF or DOCX text to build quizzes instantly.
- Student Identification Gate: Enforces a required name-entry screen at the start of each quiz to track specific student performance.
- Live Proctored Timer: A student-facing countdown timer with a red-state warning that triggers an auto-submission once time expires.
- Secure Admin Dashboard: Private database view for teachers to monitor student scores, name entries, and submission timestamps across all published links.
- Single-Attempt Lock: Logical enforcement that prevents students from retaking the same quiz twice while allowing them to view previous results on the same URL.
- Personalized Results Feedback: After submission, students view a detailed breakdown of their score and explanations without seeing other candidates' data.
- Custom Admin Messaging: Admin capability to set a custom quote or welcome message that appears prominently on the student's entry screen.

## Style Guidelines:

- Primary color: Sophisticated Deep Indigo (#5353C4) for a feeling of academic focus and reliability.
- Background color: Ultra-light muted lavender (#F5F5FA) to provide a high-contrast, distraction-free testing environment.
- Accent color: Vibrant Cerulean (#3D92ED) used exclusively for progress indicators and critical 'Submit' actions.
- Headline font: 'PT Sans' (Sans-serif) for its friendly yet authoritative tone. Body font: 'Inter' (Sans-serif) for maximum legibility within multiple-choice options.
- Outline-style icons from a precise set to maintain a professional, minimalist educator aesthetic.
- Card-based interface focusing on one question at a time to reduce cognitive load and prevent 'scroll fatigue'.
- Smooth, horizontal transitions between questions to simulate the movement through a physical exam paper.
